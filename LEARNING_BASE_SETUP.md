# Учебная материальная база MedStart

Дата проверки стартового каталога: **26.07.2026**.

## Что это за раздел

`/dashboard/knowledge` — общая медицинская библиотека для всех авторизованных
пользователей MedStart.

Она не заменяет `/dashboard/materials`:

- **Учебная база** содержит официальные источники и прошедшие модерацию
  публикации репетиторов.
- **Материалы** — личный обмен репетитора с конкретным студентом в рамках их
  занятий.

## Уровни доверия

### Официальный источник

Метка назначается только встроенным ресурсам из перечня MedStart. Репетитор не
может получить или самостоятельно установить эту метку.

Стартовый каталог использует:

- Федеральную электронную медицинскую библиотеку Минздрава России —
  <https://femb.ru/>
- Рубрикатор клинических рекомендаций Минздрава России —
  <https://cr.minzdrav.gov.ru/>
- Государственный реестр лекарственных средств —
  <https://grls.rosminzdrav.ru/grls.aspx>
- Банк документов Минздрава России —
  <https://minzdrav.gov.ru/documents>
- Методический центр аккредитации специалистов —
  <https://fmza.ru/>
- Публикации Всемирной организации здравоохранения —
  <https://www.who.int/publications>

### Проверено MedStart

Метка назначается публикации репетитора только после ручного решения владельца
или администратора. Она означает, что материал прошёл внутреннюю модерацию, но
не превращает его в официальный клинический документ.

## Сценарий репетитора

1. Открыть «Учебная база».
2. Нажать «Предложить материал».
3. Заполнить дисциплину, тип, уровень, автора и описание.
4. Загрузить PDF до 25 МБ или указать HTTPS-ссылку.
5. Подтвердить медицинскую тематику, право на публикацию и отсутствие данных
   пациентов.
6. Дождаться решения модератора.

До одобрения публикацию видят только автор и администрация.

## Проверка модератором

Перед одобрением обязательно проверить:

1. Материал относится к медицине, фармации или медицинскому образованию.
2. Автор, организация и редакция указаны честно.
3. Клинические утверждения не противоречат действующим официальным источникам.
4. Ссылка ведёт на заявленный ресурс; PDF действительно соответствует
   описанию.
5. Нет персональных данных, фотографий документов и иной медицинской тайны.
6. Нет рекламы сомнительных препаратов, псевдонауки и опасных лечебных советов.
7. У автора есть право распространять материал.
8. Коммерческий учебник не загружен целиком без лицензии правообладателя.

При отклонении модератор обязан сохранить понятную причину.

## Авторские права

ФЭМБ указывает, что размещает документы в соответствии с российским
законодательством об авторском праве. Поэтому MedStart хранит в исходном
каталоге метаданные и канонические ссылки. Копировать PDF на собственный сервер
можно только когда:

- документ опубликован с разрешением на распространение;
- правообладатель выдал MedStart лицензию;
- документ создан MedStart или репетитором, подтвердившим права.

## Безопасность файлов

Текущий MVP:

- принимает только PDF;
- проверяет расширение, MIME-тип, сигнатуру `%PDF-` и размер до 25 МБ;
- не исполняет загруженный файл внутри интерфейса;
- скрывает файл до одобрения;
- защищает чтение и запись правилами Firebase Storage.

До публичного массового запуска необходимо добавить серверный карантин:

1. новая загрузка попадает в приватный контейнер;
2. антивирус проверяет содержимое;
3. подозрительный файл блокируется;
4. только чистый файл допускается к ручной медицинской модерации;
5. результат проверки сохраняется в журнале.

Для независимости от зарубежных ограничений этот контур должен использовать
S3-совместимое объектное хранилище в российской инфраструктуре. Клиентская
загрузка вынесена в отдельный модуль, поэтому хранилище можно заменить без
перестройки страницы.

## Firebase

Добавлены:

- коллекция `knowledgeSubmissions`;
- подколлекция `users/{uid}/knowledgeBookmarks`;
- путь Storage
  `knowledge-submissions/{tutorUid}/{submissionId}/{fileName}`.

После обновления исходников опубликовать правила:

```bash
npx firebase-tools deploy --only firestore,storage
```

Без новых правил официальный статический каталог откроется, но загрузка,
публикации репетиторов, модерация и избранное будут недоступны.

## Следующие продуктовые этапы

1. Лицензионные полнотекстовые книги и официальный PDF-архив внутри MedStart.
2. Автоматическое напоминание владельцу о повторной проверке редакций.
3. Жалоба «устарело / ошибка» с приоритетной очередью.
4. Учебные подборки по семестру, дисциплине и цели.
5. Экспорт выбранного материала на умную доску занятия.
6. Серверный антивирус, журнал решений и контрольные суммы файлов.
