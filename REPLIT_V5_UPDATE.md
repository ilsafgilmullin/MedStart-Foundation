# Обновление MedStart до v5 в Replit

## Главное правило

Версии v3 и v4 последовательно устанавливать не нужно. Архив v5 уже содержит:

- связанный MVP из v3;
- MedStart Live и умную доску из v4;
- учебную материальную базу и модерацию из v5.

Для Replit используется только итоговый архив v5.

## Что сохраняется

Обновление исходников не удаляет:

- пользователей Firebase Authentication;
- документы Firestore;
- загруженные аватары;
- Replit Secrets;
- внешний видеосервер LiveKit.

Нельзя переносить в ZIP или публиковать значения Secrets.

## Рекомендуемый порядок

1. Остановить приложение кнопкой `Stop`.
2. Скачать резервный ZIP текущего проекта через меню дерева файлов Replit.
3. Применить итоговый архив v5 способом, который будет выбран по интерфейсу
   Replit на телефоне:
   - обновление существующего App сохраняет Secrets и текущую конфигурацию;
   - официальный импорт ZIP создаёт новый App и требует повторного добавления
     Secrets.
4. Установить зависимости строго из lock-файла.
5. Выполнить production-сборку.
6. Нажать `Run` и проверить вход по ролям.
7. Опубликовать Firestore и Storage Rules.
8. Проверить учебную базу под студентом, репетитором и владельцем.
9. Только после этого нажимать `Publish`.

## Контроль после запуска

- студент видит «Учебная база», поиск, фильтры и избранное;
- репетитор видит «Предложить материал» и «Мои публикации»;
- студент не видит публикацию со статусом `pending`;
- владелец видит очередь «На модерации»;
- после одобрения материал появляется в общей базе с отметкой
  «Проверено MedStart»;
- материал репетитора не получает отметку «Официальный источник»;
- личные материалы занятия продолжают работать отдельно;
- MedStart Live, чат и умная доска открываются из подтверждённого занятия.

## Официальный импорт ZIP

Replit поддерживает импорт проекта через <https://replit.com/import> → `ZIP`.
Этот путь автоматически распаковывает архив, но создаёт новый App. Для
существующего MedStart предпочтительно обновить исходники на месте, чтобы не
переносить Secrets и публикацию.
