# MedStart anatomy model attribution

The GLB files in this directory are adapted and size-optimized copies of the
Human Reference Atlas (HRA) 3D Reference Object Library release v1.3.

- Publisher: HuBMAP Consortium
- Funder: National Institutes of Health
- Source: https://humanatlas.io/3d-reference-library
- Source repository: https://github.com/hubmapconsortium/ccf-releases
- License: Creative Commons Attribution 4.0 International (CC BY 4.0)
- License text: https://creativecommons.org/licenses/by/4.0/

MedStart changes: size optimization and Meshopt compression for mobile web
delivery. No clinical or diagnostic claims are made. The models are provided
for education and spatial orientation only.

Files:

- `heart.glb` — `v1.3/models/VH_F_Heart.glb`
- `lungs.glb` — `v1.3/models/VH_F_Lung.glb`
- `liver.glb` — `v1.3/models/VH_F_Liver.glb`
- `right-kidney.glb` — `v1.3/models/VH_F_Kidney_R.glb`
- `female-pelvis.glb` — `v1.3/models/VH_F_Pelvis.glb`
